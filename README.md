# Spring Boot Hello World

A simple "Hello, World!" web application built with Java and Spring Boot.

## Prerequisites

* **Java 17** or higher
* **Maven** (or use the included Maven Wrapper `./mvnw`)

## How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd spring-boot-hello-world
   ```

2. **Run the application:**
   * **Linux/macOS:**
     ```bash
     ./mvnw spring-boot:run
     ```
   * **Windows:**
     ```cmd
     mvnw.cmd spring-boot:run
     ```

3. **Test the endpoint:**
   Open your browser and visit `http://localhost:8080/` to see `Hello, World!`.
